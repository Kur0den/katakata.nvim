# katakata.nvim
なんかこういい感じにカタカタ音がなるやつ
`aplay`がひつようだよ

## 機能
- Insert, Commandモード時にカタカタ音がなるよ
- Return, Tab時にいい感じな音がなるよ
- cmpの補完時にベルがなるよ
- Commandモード時にreturnを押すとベルがなるよ
